# 后端核心依赖（部署到容器时必装）
#
# 分组说明：核心依赖保证「TF-IDF 降级模式」下全部功能可用；
# 需要本地 embedding / Cross-Encoder 精排时，另装 requirements-ml.txt。
#
# 历史教训：这份清单曾漏了 jieba / tiktoken / scikit-learn / Pillow /
# PyMySQL / pypdf / python-docx / numpy。漏装的后果全是**静默降级**：
#   - 缺 jieba   → 违禁词单字规则失效，「第一次」会被误报（我们修过的 bug 复活）
#   - 缺 sklearn → TF-IDF 降级通道抛错，检索直接返回空，RAG 全废
#   - 缺 tiktoken→ 文档切块失败
#   - 缺 pyexec 类 → MySQL/图片/文档解析轮着挂
# 所以下面每一项都标注了「缺了会怎样」。
