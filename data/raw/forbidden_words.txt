#
# 分类与依据对照：
#   极限词    → 《广告法》第九条第(三)项  禁止"国家级""最高级""最佳"等绝对化用语
#   虚假夸大  → 《广告法》第二十八条      虚假或引人误解的内容
#   医疗功效  → 《广告法》第十七条        非医疗/药品/器械广告不得涉及疾病治疗功能
#   金融承诺  → 《广告法》第二十五条      不得对未来效果、收益作保证性承诺
#   伪造资质  → 《广告法》第九条第(二)项  不得使用国家机关名义或形象；另见各平台审核规范
#
# 维护约定：
#   1. 新增词必须同时给出「分类」与「依据」，否则无法审计
#   2. 医疗/金融/伪造资质类**刻意不给替换建议**——这类内容应改写或不用，
#      "根治→改善"这种替换本身就是误导
